Features
Everything you need.
Nothing you don't.

A lean self-hosted portal. Students register, upload their SSH key, and get a running VM in under a minute.

Under 60 seconds to a VM
Students self-register and deploy without waiting for IT. Resources are pre-configured per template.
SSH key authentication
No passwords. Students bring their own key pair. Works with VS Code Remote, PuTTY, and any terminal.
Scale by adding nodes
Proxmox cluster-aware. Add a refurbished desktop and capacity grows instantly — no cloud bills.
Admin approval flow
Teachers control who gets access. Review and approve registrations before VMs are provisioned.
On-premise · GDPR-friendly
All data stays on your servers. No student data in the cloud. Ideal for Belgian and Dutch institutions.
Simple Docker install
One Docker Compose file on your Proxmox node. Updates via image pull. No infra expertise required.
How it works
Up and running in four steps

For IT, setup takes under an hour. For students, it's a two-minute self-service flow.

01
Install SpinLab
Run the Docker Compose on your Proxmox node. Done in under an hour.
02
Students register
They upload their SSH public key and await admin approval via the portal.
03
VM is deployed
SpinLab picks the best node and provisions a Linux VM automatically.
04
Connect via SSH
Student connects immediately with their private key from any terminal.
